# ExtMaster

一款强大的 Chrome/Edge 扩展管理工具，帮助你高效管理浏览器扩展。

![版本](https://img.shields.io/badge/版本-1.0.1-blue) ![Manifest](https://img.shields.io/badge/Manifest-V3-green) ![许可证](https://img.shields.io/badge/许可证-MIT-lightgrey)

## 🎯 核心功能

### 1. 扩展管理
- **一键启用/禁用**：快速切换扩展状态
- **批量操作**：支持按分组批量启用/禁用
- **扩展详情**：查看扩展详细信息
- **卸载扩展**：安全卸载不需要的扩展

### 2. 分组管理
- **创建分组**：自定义分组名称和高亮颜色
- **拖拽分配**：从未分组列表拖拽扩展到分组
- **分组排序**：拖拽调整分组顺序
- **批量控制**：一键启用/禁用整个分组的扩展
- **成员管理**：查看和管理分组内的扩展

### 3. 自动化规则
- **URL 匹配**：使用通配符模式匹配网址
  - 示例：`*://*.github.com/*` 匹配所有 GitHub 页面
  - 示例：`https://mail.google.com/*` 匹配 Gmail
- **自动执行**：访问匹配网址时自动启用/禁用指定扩展
- **多条规则**：支持创建多条自动化规则
- **规则开关**：单独控制每条规则的启用状态

### 4. 排序功能
- **默认排序**：按浏览器默认顺序排列
- **激活优先**：已启用的扩展排在前，已禁用的排在后
- **手动排序**：拖拽扩展卡片调整顺序（分组独立）

### 5. 主题切换
- **浅色主题**：适合白天使用
- **深色主题**：适合夜间使用，保护视力

### 6. 数据管理
- **备份配置**：导出规则、分组、排序、主题等完整配置
- **恢复配置**：从备份文件恢复所有设置
- **导出名称**：导出所有扩展名称列表（纯文本）

### 7. 浏览器适配
- **自动检测**：自动检测 Chrome 或 Edge 浏览器
- **商店切换**：手动选择 Chrome 商店或 Edge 商店
- **自定义 URL**：支持自定义扩展商店地址

## 🚀 安装使用

### 开发者模式安装
1. 打开 Chrome/Edge 浏览器
2. 进入扩展管理页面：`chrome://extensions/` 或 `edge://extensions/`
3. 开启「开发者模式」
4. 点击「加载已解压的扩展程序」
5. 选择 `ExtMaster` 文件夹

### 使用说明
1. **主界面**：点击工具栏中的 ExtMaster 图标打开主弹窗
2. **分组筛选**：点击分组标签筛选该分组的扩展
3. **快捷操作**：鼠标悬停扩展卡片显示启用/禁用和详情按钮
4. **右键菜单**：右键点击扩展卡片打开上下文菜单
5. **分组管理**：点击设置按钮 →「管理分组」打开分组管理页面
6. **自动化规则**：点击设置按钮 →「管理规则」打开规则管理页面

## 🔧 技术架构

### Manifest V3
- 使用最新的 Manifest V3 标准
- 后台脚本使用 Service Worker
- 内容安全策略（CSP）配置

### 权限说明
- `management`：管理扩展（启用/禁用/卸载）
- `storage`：本地存储配置数据
- `tabs`：访问标签页信息（用于自动化规则）
- `host_permissions`：`<all_urls>` 访问所有网址（用于 URL 匹配规则）

### 数据存储结构
```javascript
{
  theme: 'light' | 'dark',              // 主题设置
  sortModes: { [groupId]: 'default' | 'enabledFirst' | 'manual' },  // 分组排序模式
  manualOrders: { [groupId]: string[] }, // 分组手动排序顺序
  groups: [                               // 分组列表
    {
      id: string,
      name: string,
      color: string,
      members: string[]                   // 扩展 ID 数组
    }
  ],
  rules: [                               // 自动化规则
    {
      id: string,
      urlPattern: string,                // URL 匹配模式
      actions: [                         // 执行动作
        {
          extId: string,               // 扩展 ID
          enabled: boolean              // 启用/禁用
        }
      ],
      enabled: boolean                  // 规则是否启用
    }
  ],
  autoRuleEnabled: boolean,             // 自动化规则总开关
  browserConfig: {                      // 浏览器配置
    type: 'auto' | 'chrome' | 'edge' | 'custom',
    customUrl: string
  }
}
```

## 🛡️ 安全特性

### v1.0.1 安全修复
- **URL 模式验证**：限制通配符数量（最多 10 个 `*`）
- **危险字符过滤**：禁止在 URL 模式中使用正则特殊字符
- **输入长度限制**：URL 模式最大 200 字符
- **备份数据验证**：恢复备份时验证数据结构和类型
- **自定义 URL 验证**：仅允许 HTTP/HTTPS 协议，禁止 `javascript:` 和 `data:` 协议

详见：[安全修复报告](doc/安全修复报告v1.0.1.md)

## 📝 开发说明

### 文件说明

#### background.js
- 后台 Service Worker
- 负责扩展状态管理、自动化规则执行、消息传递
- 使用 `chrome.management` API 管理扩展
- 使用 `chrome.storage.local` API 存储数据

#### popup.js
- 主弹窗交互逻辑
- 扩展列表渲染、分组筛选、排序、拖拽排序
- 主题切换、设置面板、上下文菜单
- 备份/恢复功能实现

#### groups.js
- 分组管理页面逻辑
- 分组创建/编辑/删除
- 分组拖拽排序
- 扩展拖拽分配到分组
- 分组内扩展批量操作

#### rules.js
- 自动化规则管理页面逻辑
- 规则创建/编辑/删除
- URL 模式转换为通配符
- 规则操作配置

#### shared.js
- 共享工具函数
- 扩展列表获取、存储读写、主题应用
- 排序函数、URL 匹配、ID 生成

### 样式设计
- CSS 变量实现主题切换
- 响应式设计，弹窗宽度 360px
- 分组管理页面宽度 680px
- 规则管理页面宽度 560px
- 支持拖拽视觉效果

## 🌟 使用场景

### 场景 1：工作/娱乐模式切换
- 创建「工作」和「娱乐」两个分组
- 工作分组包含开发工具、广告拦截等扩展
- 娱乐分组包含视频下载、翻译等扩展
- 快速切换分组启用状态

### 场景 2：自动化规则
- 访问 GitHub 时自动启用「GitHub 增强」扩展
- 访问购物网站时自动启用「价格比较」扩展
- 访问银行网站时自动禁用所有不必要的扩展（提升安全性）

### 场景 3：扩展整理
- 将 50+ 个扩展按功能分组
- 使用手动排序将常用扩展排在前面
- 一键查看某个分组的扩展状态
